# Pokétone (ポケトーン) - ポケモン種族値音あてクイズ

ポケモンの種族値（HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ・合計）を音階（メロディ）へと変換し、耳で聴いた音だけを頼りに正解のポケモンを推理・回答する新感覚のブラウザゲームです。

---

## 🎮 主な機能

### 1. クイズモード (メイン機能)
- **2段階の難易度選択**:
  - **ノーマルモード**: 合計種族値460以上またはメガシンカポケモンから出題（初心者〜中級者向け）
  - **ハードモード**: 全世代・全フォルムの全ポケモンから出題（上級者向け）
- **音響メロディ再生システム**:
  - Web Audio APIを活用し、種族値の数値を周波数（Hz）にリアルタイム変換して合成再生。
  - HP → こうげき → ぼうぎょ → とくこう → とくぼう → すばやさ → 合計音 の順に流れます。
  - サウンド波形ビジュアライザーアニメーションが音に合わせて躍動します。
- **ミュウの基準音 (All 100) 聴き比べ**:
  - 全ステータスが100であるミュウのフラットなメロディをワンタップで再生可能。正解の音が基準より高いか低いかを比較して推測できます。
- **5問ミス時の「鳴き声ヒント」アンロック**:
  - 5回間違えると、正解ポケモンの公式鳴き声が聴けるヒントボタンが解放されます。
- **回答履歴とステータス比較**:
  - 回答したポケモンのアイコン、種族値一覧、正解との合計値の差分（+○ / -○）が表示され、そのポケモンの音も聴き直せます。
- **フォルム選択パネル**:
  - リージョンフォームやメガシンカなど別の姿が存在するポケモンを入力した際、どの姿かを視覚的に選んで回答できます。

### 2. ポケモン図鑑
- **全ポケモンの種族値・メロディ試聴**:
  - 通常種に加え、メガシンカ・ゲンシカイキ、リージョンフォーム（アローラ・ガラル・ヒスイ・パルデア）まで網羅。
  - カードを選択すると詳細モーダルが開き、種族値メロディ試聴や安全な鳴き声再生が可能です。
- **高速検索・柔軟な絞り込み**:
  - ポケモン名（ひらがな・カタカナ・図鑑番号）によるインクリメンタル検索。
  - フォルム別（通常・メガ・リージョン・その他）、18タイプ別の複数選択フィルタ。
  - 合計種族値順、各ステータス（HP・攻撃・特攻・素早さ等）順のソート。
- **パフォーマンス最適化**:
  - 仮想スクロール（IntersectionObserverによる無限スクロール）で1,200匹以上のデータも軽快に描画。
  - PokeAPIからのデータ取得結果を `localStorage` にキャッシュ。

### 3. セキュリティ & チート防止機構
- **カンニング防止 (画面離脱検知)**:
  - クイズプレイ中に別タブや外部アプリを開く行為を検知し、警告モーダルを表示（複数回離脱で失格）。
- **コンソール・DevTools対策**:
  - クイズ出題中は、開発者ツールやコンソールから正解データ（`_secretQuizTarget`）を直接覗き見できないようプロパティ保護。
  - 右クリックやショートカットキーによるコンソール起動を無効化。
- **堅牢なセキュリティポリシー**:
  - Content Security Policy (CSP) による外部スクリプトの不正インジェクション遮断。
  - 外部CDNリソースに対する Subresource Integrity (SRI) 改ざん検証。
  - 画像通信遮断時でも壊れないインラインSVGモンスターボールによるフォールバック。

## 🛠 技術スタック

| 分野 | 使用技術 |
| :--- | :--- |
| **フロントエンド** | HTML5, CSS3, JavaScript (Vanilla ES6+) |
| **スタイル / UI** | Tailwind CSS (CDN版 3.4), FontAwesome 6, Google Fonts (Noto Sans JP / Inter) |
| **音声処理** | Web Audio API (オシレーター合成・ゲイン制御・音階マッピング) |
| **データソース** | [PokeAPI](https://pokeapi.co/) (公式パラメータ、公式アートワーク、鳴き声音源) |
| **データ管理** | LocalStorage API (オフラインキャッシュ & 高速起動) |

## 🚀 使い方・起動方法

1. リポジトリまたはフォルダ内の `index.html` をお好みのモダンブラウザ（Google Chrome, Edge, Safari, Firefox等）で開きます。
2. 画面上部のタブから **「クイズ」** または **「ポケモン図鑑」** を選んでプレイ・閲覧を開始します。

※初回起動時は PokeAPI からデータをバックグラウンド取得し、ローカルキャッシュに保存します。次回以降は即座に高速起動します。
